## Known issues (not fixed, documented)

- Live mode: a model retry chain (recommend/revise) can exceed the client's request timeout on slow responses; the UI shows the retry error and the capture/proposal is kept.
- Seed (`server/scripts/seed.ts`) matches the demo account's apps by name; renaming a demo app and re-seeding would create a second copy.
- Sample mode: filler proposals (when the catalog has few matches) can cite facts only loosely related to the card.
- Renaming a select option (`update_field`) does not remap `where.value` in summary metrics or view filters that used the old value.
- Accessibility: not independently verified by the review (credits); evidence is the layout/tap-target spec and AA-checked accents only.
